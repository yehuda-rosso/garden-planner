# מתכנן הערוגות

כלי לחברי הקורס "גן הירק היצרני": בוחרים כמה רוצים מכל ירק בשבוע ואת גודל הערוגות, ומקבלים מפת ערוגות, יומן שתילה עם מיקום בערוגה, מחזור משפחות בין שתילות, ומה קוטפים בכל שבוע.

- הכל בקובץ אחד: `index.html` (HTML, CSS ו-JavaScript, בלי שרת ובלי ספריות).
- כל משתמש שומר את התכנון שלו בדפדפן שלו בלבד.
- נתוני הגידול נמצאים בראש הסקריפט (`CROPS`, `PER`). נתונים המסומנים `est:1` הם הערכה שעוד לא אושרה בקורס.
